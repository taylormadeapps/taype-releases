# TayPE Dokumentation

Willkommen in der TayPE Wissensdatenbank. TayPE ist eine craft-orientierte
DAW, gebaut rund um Entscheidungen, Klarheit und darum, die Platte fertig zu machen.

Diese Doku erklärt Interface, Workflow und die Funktionen, die man wirklich
kennen muss. Kein Technik-Tiefgang, nur wie man das Ding benutzt.
