# Lizenzierung

TayPE ist eine Einmal-kaufen-und-behalten-Anwendung. Keine Abos, keine
wiederkehrenden Gebühren, keine künstlichen Feature-Sperren.

## Bildung

TayPE ist für Schüler, Studierende und Lehrende kostenlos. Meldet euch auf
[Instagram](https://instagram.com/ruminantrecords) oder
[Reddit](https://www.reddit.com/message/compose/?to=ruminantrecords) für einen Code.

## Barrierefreiheit

Wenn ihr Anforderungen an Barrierefreiheit habt, gibt es 33 % Rabatt. Meldet
euch über [Instagram](https://instagram.com/ruminantrecords) oder
[Reddit](https://www.reddit.com/message/compose/?to=ruminantrecords).

## Evaluation

TayPE enthält eine großzügige Evaluierungsphase, damit ihr die App richtig
ausprobieren könnt, bevor ihr kauft. Keine Watermarks, keine künstlichen Limits.

## Vereinbarung

Das About-Fenster enthält die aktuelle End User Licence in einem scrollbaren
Panel, und das signierte Installationspaket verwendet denselben Text.
