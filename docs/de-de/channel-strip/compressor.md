# Kompressor

Ein Dynamikprozessor für Pegelkontrolle und mehr Punch.

| Parameter | Standard | Bereich |
|-----------|---------|-------|
| Threshold | -12 dB | -60 bis 0 dB |
| Ratio | 2:1 | 1:1 bis 20:1 |
| Makeup Gain | 0 dB | 0 bis 24 dB |
| Attack | 30 ms | 0.1 bis 100 ms |
| Release | 100 ms | 10 bis 2 000 ms |
| Knee | 6 dB | 0 bis 12 dB |
| Sidechain low-cut | On | feste 80 Hz |
