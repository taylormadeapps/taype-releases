# Channel Strip

Jeder Track in TayPE hat einen eingebauten Channel Strip. Das Signal läuft in
dieser Reihenfolge:

**Input → Trim → Preamp → Filters → EQ → Compressor → Inserts → Fader → Pan → Output**

Jede Sektion kann separat aktiviert oder gebypasst werden.
