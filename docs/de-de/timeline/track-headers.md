# Track-Header

Jeder Track-Header zeigt diese Bedienelemente:

![Track-Header](../../../assets/img/docs/track-headers.png)

- **Farbstreifen**
- **Track-Name**
- **Tags**
- **R**
- **MON**
- **Bus**
- **M**
- **S**
- **Tag-Pills**
- **I/O-Labels**
- **Mini-Meter**

## Tag Cloud

Ein Klick auf **Tags** öffnet die Tag-Cloud für diesen Track.
