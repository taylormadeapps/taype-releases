# Die Timeline

Die Timeline zeigt eure Session im Zeitverlauf. Tracks laufen von oben nach
unten, Zeit läuft von links nach rechts, und der Tape Head markiert die
aktuelle Wiedergabeposition.

![Timeline-Übersicht](../../../assets/img/docs/timeline-overview.png)

## Aufbau

Links stehen die **Track-Header** mit ihren Bedienelementen. Im Hauptbereich
liegen die **Clips** mit ihren Wellenformen.

Oben zeigt das **Lineal** die Zeit. Mit **T** wechselt ihr zwischen
Minuten:Sekunden und bars|beats. Jeder Cut kann seinen eigenen Nullpunkt haben.

Unten liegt die **Transportleiste** mit Wiedergabe, BPM, Positionsanzeige,
Cut-Aktionen und Cut-Auswahl.

Neben dem DSP-Meter sitzt ein kleiner **MCP**-Lock-Indikator. Er leuchtet rot,
wenn eine MCP-Transaktion aktiv ist.

### Lineal-Steuerung

- **Channel Strip**
- **+**
- **Metronome**
- **Snap**
- **Ruler Mode**

Per Rechtsklick im oberen Lineal öffnet ihr:

- **Set 0 at Playhead**
- **Reset 0 to Start**
