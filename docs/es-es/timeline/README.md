# La línea de tiempo

La timeline es donde ves tu sesión desplegada en el tiempo. Las pistas van de
arriba abajo, el tiempo de izquierda a derecha y el cabezal marca la posición
actual de reproducción.

![Vista general de la timeline](../../../assets/img/docs/timeline-overview.png)

## Diseño

A la izquierda están las **cabeceras de pista**. En el área principal están los
**clips** con sus formas de onda.

La **regla** superior muestra el tiempo. Pulsa **T** para alternar entre
minutos:segundos y bars|beats. Cada Cut puede tener su propio punto cero.

La **barra de transporte** vive abajo e incluye reproducción, BPM, posición y
acciones de Cut.
