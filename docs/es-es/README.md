# Documentación de TayPE

Bienvenido a la base de conocimiento de TayPE. TayPE es una DAW centrada en
el oficio, la decisión, la claridad y en terminar discos de verdad.

Estos documentos cubren la interfaz, el flujo de trabajo y las funciones que
merece la pena conocer. Sin inmersiones de ingeniería: solo cómo usarlo.
