# Canal

Cada pista en TayPE tiene un canal integrado. La señal fluye así:

**Input → Trim → Preamp → Filters → EQ → Compressor → Inserts → Fader → Pan → Output**

Cada sección puede activarse o bypassarse de forma independiente.
