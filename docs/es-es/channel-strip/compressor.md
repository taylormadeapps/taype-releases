# Compresor

Un procesador de dinámica para controlar nivel y añadir pegada.

| Parámetro | Por defecto | Rango |
|-----------|---------|-------|
| Threshold | -20 dB | -60 a 0 dB |
| Ratio | 4:1 | 1:1 a 20:1 |
| Makeup Gain | 0 dB | 0 a 24 dB |
| Attack | 10 ms | 0.1 a 100 ms |
| Release | 100 ms | 10 a 2 000 ms |
| Knee | 6 dB | 0 a 12 dB |
| Sidechain low-cut | Off | 80 Hz fijo |
