# Monitor de rendimiento

El monitor de rendimiento muestra el desglose DSP por pista con columnas de CPU
separadas para **Preamp/Summing** y **Plugin**.

La fila **CPU** muestra el uso combinado de la app TayPE y `taype-sandbox`
en todos los nucleos logicos (0-100 %): verde para la app y azul para el
sandbox.
