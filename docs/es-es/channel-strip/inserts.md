# Inserciones

Cuatro slots en serie para plugins VST3. Haz clic en un slot vacío para cargar
un plugin. Clic derecho en uno cargado para bypass, remove u abrir el editor.

En pistas archivadas, los inserts activos o en bypass aparecen en rojo como
offline en la vista de archivo. TayPE conserva el estado guardado del plugin
para cuando desarchives la pista, pero descarga el plugin hospedado y bloquea
la edición mientras la pista está archivada. Puedes quitar un slot o desactivar
un insert activo; cargar, cambiar, abrir, hacer bypass, reactivar, arrastrar,
cambiar rutas, ajustar wet/dry o cargar presets requiere desarchivar primero.

## Taype Drive XTALK

Taype Drive mirrors the channel-strip preamp XTALK control. In stereo non-clean modes, XTALK blends left and right into each other before the drive/preamp stage, using the same power-law taper and defaulting to `0.0`.
