# Licencias

TayPE es una aplicación de pagar una vez y conservar. Sin suscripciones, sin
cuotas recurrentes y sin bloqueo de funciones.

## Educación

TayPE es gratis para estudiantes y educadores. Escríbenos por
[Instagram](https://instagram.com/ruminantrecords) o
[Reddit](https://www.reddit.com/message/compose/?to=ruminantrecords) para
obtener un código.

## Accesibilidad

Si tienes necesidades de accesibilidad, TayPE tiene un 33 % de descuento.

## Evaluación

TayPE incluye un periodo de evaluación generoso para probarlo de verdad antes
de comprar. Sin marcas de agua ni limitaciones artificiales.
