# Τεκμηρίωση TayPE

Καλώς ήρθατε στη βάση γνώσεων του TayPE. Το TayPE είναι ένα DAW χτισμένο γύρω από τη δέσμευση,
την καθαρότητα και την υλοποίηση του δίσκου.

Αυτά τα έγγραφα καλύπτουν τη διεπαφή, τη ροή εργασίας και τα χαρακτηριστικά που πρέπει
να γνωρίζετε. Καμία τεχνική ανάλυση - απλώς πώς να χρησιμοποιήσετε το πράγμα.
