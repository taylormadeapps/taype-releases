# Leiðsögn

## Skruna

- **Músarhjól**
- **Lárétt trackpad hreyfing**
- **Hægri-smellur og drag vinstri/hægri**

## Zoom

- **Cmd + hjól**
- **Option + hjól**
- **= / -**
- **Shift+-**
- **Shift+=**

Við hægrismelltu pan/zoom-dragi sýnir TayPE stækkunargler-bendil þar til sleppt er.

## E-Zoom

Ýttu á **E** til að passa sýn að völdu clipi.
