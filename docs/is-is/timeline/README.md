# Tímalínan

Tímalínan sýnir setuna þína í tíma. Lög fara ofan frá og niður, tíminn frá
vinstri til hægri og tape head sýnir núverandi spilunarstöðu.

![Yfirsýn yfir tímalínu](../../../assets/img/docs/timeline-overview.png)

## Uppsetning

Vinstra megin eru **hausar laga**. Í aðalsvæðinu eru **klipur** með bylgjuformi.

Reglustikan efst sýnir tíma. Með **T** skiptir þú á milli tíma og bars|beats.
