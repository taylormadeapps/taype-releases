# TayPE skjöl

Velkomin í þekkingargrunn TayPE. TayPE er DAW sem leggur áherslu á handverk,
ákvarðanir, skýrleika og að klára raunverulegar upptökur.

Þessi skjöl fjalla um viðmótið, vinnuflæðið og eiginleikana sem þú þarft að
þekkja. Engar tæknilegar djúpkafanir, bara hvernig á að nota þetta.

![TayPE tímalína](../../assets/img/docs/timeline-overview.png)

[r/taype](https://www.reddit.com/r/taype/) eða senda skilaboð á
