# Hljóðmixerinn

Ýttu á **M** til að skipta á milli tímalínu og mixer.

Mixerinn sýnir eina rásarræmu fyrir hvert lag, raðað frá vinstri til hægri.
Master bus er alltaf lengst til hægri.

![Yfirsýn yfir mixer](../../assets/img/docs/mixer-overview.png)

## Uppsetning rásarræmu

Hver ræma sýnir frá toppi niður:

- **Nafn lags**
- **Input selector**
- **Control buttons**: M, S, R, MON, A, B
- **Output selector**
- **Preamp section**
- **Filter section**
- **EQ section**
- **Compressor section**
- **Insert slots**
- **Pan**
- **Fader**
- **Peak meter**
