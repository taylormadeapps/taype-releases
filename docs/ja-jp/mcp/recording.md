# 録音

オーディオ入力を録音するためのツールです。

---

### `record_start`

オーディオ入力を指定トラックへ録音開始します。トランスポートはオーバーダブモニタリングのために再生状態へ入ります。

このツールは `tx_begin` を必要としませんが、MCP トランザクションがアクティブな間は拒否されます。TayPE は、MCP クライアントがトランザクションを短く保ち、トランスポート操作の前に抜けることを前提にしています。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `track_id` | string | はい | 録音先トラック |

**戻り値:** `{ "recording": true, "track_id": "track_2", "position": 5.0 }`

### `record_stop`

録音を停止し、WAV を確定し、録音したクリップをトラックへ追加し、リールの作業状態を直ちに保存します。

このツールも `tx_begin` は不要ですが、MCP トランザクション中は拒否されます。

**戻り値:**
```json
{
  "recording": false,
  "clip_id": "clip_3",
  "time": 5.0,
  "duration": 12.5
}
```
