# トランザクション

複数の変更を 1 つの undo ステップにまとめるためのツールです。

---

### `tx_begin`

明示的なトランザクションを開始します。複数の変更を 1 つの undo ステップにまとめます。トランスポート停止中のみ使えます。

トランザクションは短時間で終える前提です。アクティブ中は次の制限があります。

- UI 側の構造編集がロックされる
- undo / redo がロックされる
- トランスポートコマンド（`play`、`stop`、`seek`）が拒否される
- 録音コマンド（`record_start`、`record_stop`）が拒否される
- autosave が一時停止する

接続が切れた場合、トランザクションは自動で中止され、変更はロールバックされます。ユーザーは Edit > **Release MCP Lock...** から手動で解除することもでき、トランスポートの DSP メーター横にある赤い **MCP** インジケーターを右クリックしても解除できます。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `label` | string | はい | このトランザクションの undo ラベル |

**戻り値:** `{ "tx_id": "uuid-...", "label": "Batch edit" }`

### `tx_commit`

トランザクションをコミットします。undo スナップショットを積み、変更がある場合はリールの作業状態もすぐ保存します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `tx_id` | string | はい | `tx_begin` から得たトランザクション ID |

### `tx_abort`

トランザクションを中止します。トランザクション前の状態へロールバックし、そこからエンジンを再構築し、遅延中だった autosave も破棄します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `tx_id` | string | はい | `tx_begin` から得たトランザクション ID |
