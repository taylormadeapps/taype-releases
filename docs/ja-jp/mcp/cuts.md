# Cut

1 つのリール内にある、代替タイムラインページを管理するためのツールです。

どのリールにも必ず **Main Cut** があります。Cut 同士で共有されるのは、トラック一覧、ルーティング、チャンネルストリップ状態、インサートです。クリップ、テンポ、拍子は Cut ごとです。

---

### `list_cuts`

すべての Cut を一覧し、どれが選択中かを返します。

**戻り値:**
```json
{
  "cuts": ["Main Cut", "Verse", "Chorus"],
  "selected": "Verse"
}
```

### `select_cut`

名前を指定して別の Cut に切り替えます。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `name` | string | はい | Cut 名 |

**戻り値:** `{ "selected": "Verse" }`

トランスポート停止中のみ使えます。

### `add_cut`

新しい空の Cut を作成します。新しい Cut は現在の Cut のテンポと拍子を引き継ぎ、クリップは空、名前は自動で（`Cut N`）、作成後はその Cut が選択されます。

**戻り値:** `{ "name": "Cut 2", "selected": "Cut 2" }`

### `duplicate_cut`

現在選択中の Cut を複製します。クリップには新しいクリップ ID が振られ、Cut 固有のトランスポート状態も複製されます。複製後はコピー側が選択されます。

**戻り値:** `{ "name": "Verse copy", "selected": "Verse copy" }`

### `rename_cut`

名前を指定して Cut をリネームします。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `name` | string | はい | 既存の Cut 名 |
| `new_name` | string | はい | 新しい Cut 名 |

**戻り値:** `{ "name": "Verse" }`

`Main Cut` は名前変更できません。新しい名前はリール内で一意である必要があります。トランスポート停止中のみ使えます。

### `delete_cut`

名前を指定して Cut を削除します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `name` | string | はい | Cut 名 |

**戻り値:** `{ "deleted": "Verse", "selected": "Main Cut" }`

`Main Cut` は削除できません。削除後の選択は `Main Cut` に戻ります。トランスポート停止中かつ、アクティブな MCP トランザクション内でのみ使えます。
