# トランスポート

再生、テンポ、メトロノームを操作するためのツールです。

テンポと拍子は **現在選択中の Cut** に属します。別の Cut のテンポマップを変更したい場合は、その前に Cut 系ツールでページを切り替えてください。

---

### `play`

オーディオ再生を開始します。

**戻り値:** `{ "playing": true }`

### `stop`

再生を停止します。すでに停止中なら、ヘッドを選択中 Cut のゼロ位置へ戻します。

**戻り値:** `{ "playing": false, "position": 0.0 }`

### `get_state`

現在のトランスポート状態を取得します。

**戻り値:**
```json
{
  "playing": false,
  "position": 12.5,
  "duration": 180.0,
  "zero_time_seconds": 8.0
}
```

### `seek`

再生位置を設定します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `position` | number | はい | 秒単位の位置 |

**戻り値:** `{ "position": 12.5 }`

### `set_cut_zero`

選択中 Cut のゼロ位置を、現在の再生ヘッド位置に設定します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `position` | number | いいえ | ゼロ位置（秒）。省略時は現在の再生ヘッド位置 |

**戻り値:** `{ "selected": "Verse", "zero_time_seconds": 8.0 }`

### `reset_cut_zero`

選択中 Cut のゼロ位置をタイムライン先頭に戻します。

**戻り値:** `{ "selected": "Verse", "zero_time_seconds": 0.0 }`

### `set_transport`

テンポと / または拍子を設定します。指定した項目だけが変更されます。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `tempo` | number | いいえ | BPM |
| `numerator` | number | いいえ | 拍子の分子 |
| `denominator` | number | いいえ | 拍子の分母 |

**戻り値:** 変更後の現在トランスポート状態。

### `set_metronome`

メトロノームクリックを有効 / 無効にします。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `enabled` | bool | はい | true で有効、false で無効 |

**戻り値:** `{ "enabled": true }`
