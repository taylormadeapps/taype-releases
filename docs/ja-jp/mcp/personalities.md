# パーソナリティ

パーソナリティは、MCP 経由で AI アシスタントがどう振る舞うかを決める、スタジオテックのキャラクターです。それぞれに、ミックスや制作に対する考え方、話し方、提案の癖があります。

机の向こうに座るエンジニアが入れ替わると考えるとわかりやすいです。使えるツールもエンジンも同じですが、助言の仕方と空気感が変わります。

## 組み込みパーソナリティ

TayPE には 11 種類のスタジオテックキャラクターが最初から入っています。

| 名前 | 雰囲気 |

| **Greg Zenner** | 直球のメンター。音の綺麗さより手触り。既定の人格。 |
| **Arena Push** | 大胆で押し出しの強い、スタジアム級のミックス |
| **Polished Depth** | 奥行きがあり、上品で、ラジオ映えする仕上がり |
| **Glue & Weight** | バス発想、コンプレッション、まとまりと重量感 |
| **Intimate Front** | 近くて質感があり、正直。ローファイでも意図がある |
| **Cinematic Air** | 空間設計重視。残響を建築のように使う |
| **Tight & Modern** | トランジェント重視、配信向けの現代的な精度 |
| **Dirty Authority** | サチュレーション、荒さ、個性。テープと真空管の手触り |

## パーソナリティの切り替え

`set_personality` ツールで切り替えるか、AI アシスタントに別のキャラクターへ変えるよう頼んでください。パーソナリティはリールごとに保持されるので、セッションごとに別のエンジニアを座らせておけます。

## カスタムパーソナリティ

`~/Documents/TayPE/Personalities/` に JSON ファイルを置くと、独自パーソナリティを追加できます。

```json
{
  "name": "My Custom Tech",
  "prompt": "You are a laid-back studio tech who speaks like a surfer..."
}
```

このフォルダー内の `.json` は自動的に読み込まれ、組み込みパーソナリティと並んで表示されます。

## パーソナリティができること / できないこと

パーソナリティが変えるのは、話し方、提案の方向、ワークフローの癖です。エンジンの動作、音声処理、セッションの保存方法そのものは変わりません。パーソナリティが原因でミックスが壊れたり、データが壊れたりすることはありません。変わるのは「誰が卓に座っているか」だけです。
