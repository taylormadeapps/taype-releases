# ユーティリティ

フィードバック送信とライセンス管理のためのツールです。

---

## フィードバック

### `submit_feedback`

フィードバックまたはクラッシュレポートを送信します。実行時のシステム情報（バージョン、OS、CPU アーキテクチャ、オーディオインターフェイス、サンプルレート、バッファサイズ、読み込み中プラグイン数、トラック数、トランスポート状態、ライセンスティア）を収集し、ユーザーの説明文と一緒に TayPE チームへ送ります。

このツールを呼ぶ前に、送信される内容をすべてユーザーへ見せ、明示的な確認を取る必要があります。承認なしにマシンの外へ出してはいけません。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `description` | string | はい | ユーザーによる問題説明 |
| `type` | string | いいえ | `"feedback"`（既定）または `"crash"` |

**戻り値:** 収集された送信ペイロード（送信内容の確認に使えます）。

---

## ライセンス

### `get_license_status`

現在のライセンス状態を取得します。

**戻り値:**
```json
{
  "licensed": true,
  "founder": true,
  "licensee": "Tom Taylor",
  "tier": "founder",
  "sequence": 1,
  "valid_from": "2025-01-01",
  "valid_to": "2026-01-01",
  "era": 1
}
```

### `show_license_dialog`

ライセンスダイアログを表示します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `type` | string | いいえ | `"nag"`、`"licensed"`、`"auto"`（既定） |
