# クリップ

タイムライン上のオーディオクリップを配置、移動、管理するためのツールです。

---

### `add_clip`

オーディオファイルをトラック上のタイムライン位置に配置します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `track_id` | string | はい | 対象トラック ID |
| `path` | string | はい | オーディオファイルの絶対パス |
| `time` | number | いいえ | 秒単位のタイムライン位置（既定: 0.0） |
| `duration` | number | いいえ | クリップ長（秒、既定: ファイル全体） |
| `clip_start` | number | いいえ | ソースファイル内で実際に再生が始まるオフセット（秒） |
| `name` | string | いいえ | クリップ名 |

**戻り値:** `{ "id": "clip_1", "time": 0.0, "duration": 45.2 }`

### `set_clip`

クリップをタイムライン上で移動するか、別トラックへ動かします。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `id` | string | はい | クリップ ID |
| `time` | number | いいえ | 新しいタイムライン位置（秒） |
| `track_id` | string | いいえ | 移動先トラック ID |

`time` または `track_id` のどちらか 1 つ以上が必要です。

**戻り値:** 更新後のクリップオブジェクト。

### `remove_clip`

クリップを削除します。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `id` | string | はい | クリップ ID |

**戻り値:** `{ "removed": "clip_1" }`

### `get_clips`

クリップ一覧を取得します。必要ならトラックで絞り込みできます。

| パラメータ | 型 | 必須 | 説明 |
|-------|------|----------|-------------|
| `track_id` | string | いいえ | 特定トラックで絞り込む（省略時は全トラック） |

**戻り値:**
```json
{
  "clips": [
    {
      "id": "clip_1",
      "name": "take1.wav",
      "track_id": "track_1",
      "time": 0.0,
      "duration": 45.2,
      "clip_start": 0.0,
      "record_alignment_offset": 0.0,
      "source_start": "00:00.000",
      "source_end": "00:45.200",
      "file": "/path/to/take1.wav"
    }
  ]
}
```

`clip_start` は実際の再生開始オフセットです。録音で作ったクリップでは
自動の録音位置合わせがここに含まれることがあり、その分は
`record_alignment_offset` に別で出ます。`source_start` / `source_end` は
ユーザーのトリム位置を表すので、触っていない録音直後のテイクは
`00:00.000` のままです。
