# はじめる

TayPE は、記録、リッスン、コミットという単純なループを中心に構築されています。無限のメニューや埋もれた機能はありません。主要なワークフローがどのように組み合わされるかは次のとおりです。

## 2つの視点

TayPE には 2 つの主要なビューがあります。 **M** を押してそれらを切り替えます。

**タイムライン** - 時間の経過とともに移動するトラック、クリップ、テープ ヘッドが表示されます。ここで録音、アレンジ、編集を行います。

**ミキサー** - サウンドを形成します。フェーダー、EQ、コンプレッション、プラグインインサート。トラックごとに 1 つのチャンネル ストリップが左から右にレイアウトされます。

## リールのオープンと作成

TayPE により **リール ブラウザ**が開きます。ここは、既存のリールを開いたり、最近のリールにジャンプしたり、新しいリールを作成したりする場所です。

必要なリールまたはパックが通常のライブラリの外にある場合は、リール ブラウザで **ファイルから開く...** を使用します。

システムの一時フォルダーから開かれた一時バンドルは [最近] に保存されないため、スクラッチ作業のテストや解凍によって通常のリール リストが汚染されることはありません。

リールを作成すると、TayPE は `~/Documents/Taype/Reels` をルートとするネイティブ保存ダイアログを開き、`Untitled Reel.taype` のようなバンドル名を提案します。場所とリール名の両方をその 1 つのステップで変更できます。

動作状態は、トランスポートの停止中に自動的に保存されます。管理するための個別の保存コマンドはありません。名前付きチェックポイントを作成する場合は、**Cmd+S** を押します。これは、後で戻ることができる、砂の中の意図的なラインです。

古い歴史を引きずらずに新たなスタートを切りたい場合は、リール ブラウザの **Thin Reel...** を使用してください。 TayPE は、間引きされたバンドルをどこに置くかを尋ね、デフォルトで現在の名前に `Thinned` を追加し、ソース リールはそのままにしておきます。ストレージが不足している場合は、間引いたリールを確認した後、Finder で古いリールを削除してください。

リール ブラウザ履歴では、デフォルトのフィルタリングされたビューはタグ駆動型です: 現在の状態、名前付きチェックポイント、およびブランチ起点タグ。自動保存から分岐する場合、TayPE はそのソース コミットにタグを付けて、分岐ノードとして表示されたままにします。単純な自動保存ヘッドは、完全な保存ごとの証跡に対して **自動保存を表示** をオンにするまで非表示のままです。履歴ビューは、連続した垂直の Git スタイルのグラフです。最古が一番上、最新が一番下、現在のブランチがメインスパイン、サイドブランチが右にオフセットされます。同じブランチの自動保存は、コミットごとに深くカスケードされるのではなく、1 つのレーンに留まります。履歴ヘッダーで **フォーカス** を使用すると、古いコミットやサイド ブランチを調べた後にブラウザを現在の状態に戻すことができます。

2. 入力ラベルをクリックしてトラックの入力を設定します（例：「1-2」）。
オーディオインターフェイスからステレオペアリングします)。
3. **R** ボタンをクリックするか、 を押して、トラックを録音用に準備します。
トラックヘッダーの R ボタン。
4. **Return** を押して録音を開始します。停止するには、もう一度 **Return** を押します。

## 編集

編集はトランスポートが停止しているときにのみ行われます。これは仕様によるものです - TayPE は再生をクリーンに保ち、構造的な変更から切り離します。

- **クリップをクリックして選択します**
- **クリップをドラッグ**して移動します (時間の場合は水平方向、変更の場合は垂直方向)
トラック)
- **Cmd+ドラッグ**してクリップを新しい位置にコピーします
- **S** - 選択したクリップをテープヘッドで分割します
- **Cmd+D** - クリップを連続して複製します
- **Cmd+X / Cmd+C / Cmd+V** - 切り取り、コピー、貼り付け

クリップの端をドラッグしてトリミングします。これは非破壊的であり、元のオーディオが変更されることはありません。

## 元に戻すとやり直し

- **Cmd+Z** - 元に戻す
- **Cmd+Shift+Z** - やり直し

すべてのアクションは元に戻すことができます。フェーダーの移動、クリップの編集、トラックの変更、そのすべて。

## TayPEについて

**TayPE > About TayPE** を使用して、アプリの正確なバージョン/ビルド、出荷された依存関係のバージョンとライセンス (JUCE、Signalsmith Stretch、NeuralAmpModelerCore、およびリール履歴に使用されるシステム Git ランタイム) を表示します。

## ポップアップヘルプ

**ヘルプ -> ポップアップ ヘルプ** またはトランスポート バーの右端の **?** トグルを使用して、トランスポート、タイムライン、ミキサー、チャンネル ストリップ全体のホバー ヘルプをオンにします。ポップアップ ヘルプが有効な場合、**?** ボタンが緑色に点灯します。ポインタをコントロール上に約 **0.7 秒**置くと、TayPE がそのコントロールの動作を説明します。

## RTFM とドキュメント検索

**[ヘルプ] -> [詳細マニュアルを読む]** を使うと、対応する GitBook の言語版が存在する場合はその言語で TayPE ドキュメントを開きます。現在のアプリ言語に公開済みのドキュメント節がまだない場合は、英語版にフォールバックします。

macOS では、**ヘルプ** メニュー上部の検索フィールドでドキュメントを検索できます。そこで Return キーを押すか検索ボタンをクリックすると、Apple ヘルプ検索の代わりに、対応する GitBook 言語版でブラウザ検索を開きます。その言語の節がない場合は英語版にフォールバックします。

**ヘルプ -> TayPE ドキュメントの検索...** は、明示的な docs-search フォールバックとしてすべてのプラットフォームで引き続き利用できます。

## アプリの言語

**[ヘルプ] -> [言語]** を使用して、TayPE が次回起動時に使用するアプリの言語を選択します。 TayPE は、選択内容をユーザー設定に直ちに書き込み、新しく選択された言語で確認モーダルを表示し、インターフェイス全体がそれを正しく認識するために再起動するように求めます。

メニューには、TayPE 言語フォルダーに実際に存在し有効な言語ファイルのみが表示されるため、アプリのビルドを変更せずにカスタムまたは進行中の言語パックをテストできます。

現在のアルファ バンドルには、**英語 (英国)** に加えて、**America English**、**Français**、**Deutsch**、**Español**、**Íslenska**、**Esperanto**、および **日本語** のドラフト アプリ パックが同梱されています。 TayPE 言語フォルダーで有効な言語 CSV ファイルを追加または削除すると、そのメニューは実際にインストールされているものと一致するように更新されます。

## ギルドのおすすめ

**[ツール] -> [ギルド ピック]** を使用して、実際に記録を作成できると評価した厳選されたプラグインの小さなリストを表示します。

ギルドピックには次の免責事項があります。

**所属はありません。リベートはありません。記録を作成するために私たちが心から評価しているプラ​​グインだけです。**

リストは **無料**、**Honourware**、**有料スリーパー**、**有料プレミアム** にグループ化されており、各項目ごとにブラウザで公式ベンダー ページが開きます。

## 状態を追跡する

TayPE にはトラックについて 3 つの考え方があります。

**現在** - デフォルト。これらはあなたのアクティブな生きた軌跡です。再生中に聞こえる音。

**フォーカス** - **F** を押して、タイムラインをフィルタリングして、現在のテープ ヘッド位置にオーディオがあるトラックのみを絞り込みます。ボタンを押すとフォーカスが再計算され、作業中に揺れることはありません。録音準備済みのトラックと選択したトラックは常に表示されます。

**アーカイブ** - **A** を押してアーカイブ ビューを切り替えます。アーカイブされたトラックは完全に沈黙しており、再生も処理も CPU もありません。アーカイブは「ミュート」や「非表示」ではなく、トラックを食器棚にしまうことです。必要なときに引き戻すことができます。

## 幹線とバス

トラック ヘッダーの **B** ボタンを使用して、トラックをバスとして指定できます。バス トラックは、そこにルーティングされたすべてのトラックからのオーディオを合計し、サブミックス (ドラム バス、ボーカル バスなど) を作成できます。

トラックをバスにルーティングするには、出力ラベルをクリックし、リストからバスを選択します。

**G** (スピル) を押すと、選択したバスとそこにルーティングされたすべてのトラックのみが表示されます。サブミックスに焦点を当てるのに便利です。
