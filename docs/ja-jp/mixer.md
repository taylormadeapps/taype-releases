# ミキサー

**M** を押すと、タイムライン表示とミキサー表示を切り替えられます。

ミキサーには、各トラックにつき 1 本のチャンネルストリップが左から右へ並びます。マスターバスは常に一番右です。マウスホイールやトラックパッドで横スクロールして、各チャンネルを見渡せます。

![ミキサー全体像](../../assets/img/docs/mixer-overview.png)

## チャンネルストリップの並び

各ストリップには、上から順に次の要素が並びます。

- **トラック名** - ダブルクリックで名前変更
- **入力セレクター** - そのトラックがどのオーディオインターフェイス入力から録音するか
- **コントロールボタン** - M (ミュート)、S (ソロ)、R (録音待機)、MON (ソフトウェアモニタリング)、A (アーカイブ)、B (バス)
- **出力セレクター** - そのトラックがどこへ送るか
- **プリアンプセクション** - MODE / AG / SAFE と、常時表示の Trim、モードに応じた Drive または NAM Output Gain
- **フィルターセクション** - ハイパス / ローパスフィルター
- **EQ セクション** - 3 バンドのパラメトリック EQ
- **コンプレッサーセクション** - ダイナミクス処理
- **インサートスロット** - VST3 プラグイン用の 4 スロット
- **パンノブ** - ステレオ定位
- **フェーダー** - 音量。dB 表示付き
- **ピークメーター** - クリップインジケーター付きのステレオレベルメーター
  （表示は 4 Hz で更新され、各更新ウィンドウ内の瞬間ピークを保持します）

各処理セクションは、ヘッダーのトグルで展開 / 折りたたみできます。各部の詳細は [チャンネルストリップ](channel-strip/README.md) を参照してください。

## 使い方

**フェーダーとノブ** - クリックして上下にドラッグします。1 回のドラッグは 1 つの undo 可能な操作として扱われます。

**ボタン** (ミュート、ソロなど) - クリックで切り替えます。

**B** をオンにすると、そのトラックはバスになり、入力はデバイス入力なしに切り替わります。**B** をオフにすると、そのバスへルーティングされていたトラックは自動で切り離され、ルーティングが壊れたまま残りません。

**インサートスロット** - クリックでプラグインを読み込み、右クリックでバイパスや削除などのコンテキストメニューを開けます。

**トラック名** - ダブルクリックでその場編集できます（トランスポート停止中のみ）。

## トラック順

トラックの並び順はタイムラインと同じです。マスターバスは常に一番右に表示されます。

ミキサーで見えるトラックも、タイムライン側の表示フィルターに従います。

- **Archive View (A)** - タイムラインと同じく、現行トラックかアーカイブ済みトラックかを切り替えます
- **Focus (F)** - テープヘッド位置にクリップがあるトラックだけを表示します
- **Spill (G)** - 選択中のバスと、そこへ送られているトラックだけを表示します
