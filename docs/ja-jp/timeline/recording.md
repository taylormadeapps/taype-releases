# 録音

## ゴーストクリップ

録音中は、録音待機中トラック上に半透明の赤い「ゴーストクリップ」が伸びていき、どこに音が録られているかを示します。波形はおよそ 1 秒ごとに更新されるので、入ってきている信号の様子を確認できます。

停止すると、ゴーストクリップは最終的な波形を持つ本物のクリップに置き換わります。

## タイミング

録音されたクリップは、パンチインした位置に固定されたまま残ります。レイテンシ補正は内部で適用されるので、連続テイクでも演奏したタイミングが保たれます。

録音中に **Stop** を押すと、ヘッドは確定したテイクの終端に止まるので、さっき録った内容をすぐ目で確認できます。

## 入出力ルーティング

**Input** - トラックヘッダーの入力ラベルをクリックします。

- オーディオトラック（インストゥルメントインサートなし）: オーディオ入力のみ（Default、None、モノチャンネル、ステレオペア）
- インストゥルメントトラック（インストゥルメントインサートあり）: MIDI 入力のみ（All MIDI、Virtual Keyboard、ハードウェア MIDI デバイス、None）

トラックがインストゥルメントモードへ切り替わると、入力ルートは自動的に **All MIDI** になります。通常モードへ戻ると、MIDI ルートは既定のオーディオ入力へ戻ります。

**MON** - MON ボタンをクリックすると、生入力をそのトラックのチャンネルストリップとインサートを通した状態でモニターできます。トランスポート停止中は、MON はライブ入力だけを通し、タイムライン上のクリップは再生を始めるまで鳴りません。

**Output** - 出力ラベルをクリックして、送り先を **Master** または作成済みの任意のバストラックから選びます。

トラックのバスモードをオフにすると、そのバスへ送られていたトラックは自動的に切り離されます。オーディオインターフェイスが変わって入力チャンネルが見つからなくなった場合、入力ラベルはグレー表示になりますが、設定自体は保持され、再び接続すれば戻ります。
