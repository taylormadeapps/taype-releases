# タイムライン

タイムラインは、セッションを時間軸で見渡す場所です。トラックは上から下へ、時間は左から右へ流れます。縦線で表示されるテープヘッドが、現在の再生位置を示します。

![タイムライン全体像](../../../assets/img/docs/timeline-overview.png)

## レイアウト

左側の列にはコントロール付きの **トラックヘッダー** が並び、中央の広いエリアにはオーディオを表す波形入りの四角、つまり **クリップ** が表示されます。

上部の **ルーラー** は時間を示します。**T** を押すと、分:秒表示と bars|beats 表示を切り替えられます。各 Cut は独自のゼロ位置を持てるので、ルーラーやトランスポートのカウンターを絶対的なタイムライン先頭ではなく、曲中の任意のセクション開始から読ませることができます。bars|beats 表示では、そのゼロ位置が bar `1.1` になり、左側の小節は負の値で表示されます。

下部には **トランスポートバー** があります。中央には再生コントロール、BPM、位置表示があり、その右側ユーティリティ群の先頭に、アクティブな Cut 名を表示する Cut セレクターと、その左隣に **New / Duplicate / Rename / Delete** の Cut 操作メニューがあります。左側の表示ボタンは **Show Mixer**、**Focus**、**Tags**、**Spill**、**Archive** です。**?** のポップアップヘルプトグルはトランスポートバーの一番右にあります。

DSP メーターの隣には小さな **MCP** ロックインジケーターがあります。MCP トランザクション中は赤く点灯し、右クリックでロックを中断できます。

**Help → Popup Help** を有効にすると、ルーラーボタン、トラックヘッダーの操作子、クリップ、フェード、ゲインライン、クロスフェード領域に約 **0.7 秒** でホバーヘルプが表示されます。

### ルーラーヘッダーのコントロール

ルーラー左側には、よく使う操作が並んでいます。

- **Channel Strip** - チャンネルストリップのサイドパネルを表示 / 非表示
- **+** - 新しいトラックを追加
- **Metronome** - クリックをオン / オフ
- **Snap** - グリッドスナップをオン / オフ
- **Ruler Mode** - 時間表示と bars|beats 表示を切り替え

ルーラー上段を右クリックすると、ゼロ位置メニューが開きます。

- **Set 0 at Playhead** - 現在のテープヘッド位置を、選択中 Cut の新しい `0:00` にする
- **Reset 0 to Start** - その Cut のゼロ位置を先頭に戻す

下段の目盛り帯では、従来どおり右ドラッグでパン / ズームできます。
