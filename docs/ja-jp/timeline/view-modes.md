# 表示モード

4 つの表示フィルターで、いま必要なものだけに集中できます。すべてトグル式です。

| ショートカット | モード | 動作 |
|----------|------|-------------|
| F | Focus | テープヘッド位置にクリップがあるトラックだけを表示 |
| A | Archive View | 現行トラック表示とアーカイブ済みトラック表示を切り替え |
| G | Spill | 選択中のバス（またはマスター）と、そこへ直接送られているトラックを表示 |
| E | E-Zoom | 選択中クリップが収まるようにズーム |

録音待機中のトラックと選択中トラックは、表示フィルターの状態に関係なく常に見えます。

Focus は MCP から特定タグ付きで駆動することもでき（Focus-by-Tag）、その場合はそのタグを持つトラックだけを表示します。
