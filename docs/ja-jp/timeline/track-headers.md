# トラックヘッダー

各トラックヘッダーには次のコントロールがあります。トラック高さが極端に低いときは、一部のラベルがズームインするまで隠れます。

![トラックヘッダー](../../../assets/img/docs/track-headers.png)

## コントロール

- **カラーストリップ** - クリックして 24 色のスウォッチからトラック色を変更
- **トラック名** - ダブルクリックで名前変更（停止中のみ）。ポップアップヘルプ有効時は、ホバーでフルタイトルを表示
- **Tags** - このトラック用のタグクラウドポップアップを開く
- **R** - 録音待機（待機中は赤い丸）
- **MON** - ソフトウェアモニタリング（入力をトラックのチャンネルストリップ経由で聴く）
- **Bus** - バストラックとして指定（白いバスグリフ。アクティブ時は緑で塗りつぶし）
- **M** - ミュート（ミュート時はスピーカーに打ち消し線）
- **S** - ソロ
- **タグピル** - 高さが十分あると、割り当て済みタグがボタン列の下にピル表示される
- **I/O ラベル** - 入力元と出力先（クリックで変更）
- **ミニメーター** - 4 Hz 更新のステレオピークメーター

中サイズ以上の高さでは、ボタン列全体がタイトルのすぐ下に固定表示されます。

## タグクラウド

トラックヘッダーの **Tags** をクリックすると、タグクラウドが開きます。

- **Both / Global / Reel** でクラウドの対象範囲を切り替え
- 検索欄でタグ名をライブ絞り込み
- タグをクリックして、そのトラックへの割り当てをオン / オフ
- **New Tag** から、その場でスコープを選んで新規タグ作成:
  - **Global** タグは、このマシン上のリール間で共有されます
  - **Reel** タグはリール内に保存され、そのリールと一緒に移動します

ポップアップは複数タグを続けて付けられるよう開いたままです。外側をクリックするか **Done** を押すと閉じます。
