# ナビゲーション

## スクロール

- **マウスホイール** - トラックを上下にスクロール
- **トラックパッドの左右スワイプ** - 時間方向に左右スクロール
- **右クリックドラッグ左右** - 時間方向にパン

細いオーバーレイスクロールバーはスクロール中だけ表示され、少しすると消えます。スクロールバーのつまみを直接ドラッグすることもできます。

再生中のタイムラインはページ送り追従です。テープヘッドが右端に達すると、表示が 1 ページ先へジャンプします。

## ズーム

**横ズーム**（時間方向）:
- **Cmd + マウスホイール** - テープヘッド中心で拡大 / 縮小
- **右クリックドラッグ上下** - 下へドラッグで拡大、上へドラッグで縮小

**縦ズーム**（トラック高さ）:
- **Option + マウスホイール** - 選択中トラックを基準に拡大 / 縮小
- **Cmd+Option+=** / **Cmd+Option+-** - キーボードで拡大 / 縮小
- **Cmd+Option+0** - トラック高さを既定値に戻す

## E-Zoom

**E** を押すと、選択中クリップがちょうど収まるようにズームします。もう一度 **E** を押すと、元のズーム率とスクロール位置に戻ります。

## シーク

クリップ以外のタイムライン上ならどこでもクリックしてテープヘッドを移動できます。ルーラー上をクリックすれば、下に何があっても常にシークします。
上段ルーラーの右クリックでは、選択中 Cut のゼロ位置メニューが開きます。
下段の目盛り帯を右ドラッグすると、従来どおりパン / ズームできます。

**Option+クリック** は、クリップの上でも常にシークです。クリックしたままドラッグすればスクラブできます。

スナップがオンのときは、ルーラー上のシークやシークドラッグも近くのクリップ先頭 / 末尾に吸着するので、**Set 0 at Playhead** を使う前にテープヘッドを合わせやすくなります。

## マーカー

マーカーは現在の Cut に属し、絶対的なタイムライン時間に固定されます。テンポ、拍子、Cut のゼロ位置を変えても、マーカー自体は動きません。

- 上段ルーラーを右クリックして **Add Marker at Playhead** を選ぶと、現在のテープヘッド位置にマーカーを追加できます
- 各マーカーはタイムライン全体を縦に貫く細い線として描かれ、ルーラー上では線の右側に小さなラベルタブが表示されます
- マーカーは左右へドラッグして移動できます。スナップがオンなら、ルーラーのシークと同じ挙動で吸着します
- マーカータブをダブルクリックすると名前を付けられます。名前を空欄にすると、現在の番号が表示されます
- マーカータブを右クリックすると、削除や色変更ができます
- 長いラベルは必要に応じてタブ内で省略表示されます。ポップアップヘルプを有効にしてホバーすると全文を確認できます
- 同じタイムスタンプに 2 つのマーカーが置かれた場合は、既存のマーカーが優先され、重複分は折りたたまれます

トランスポートの **<** / **>** ボタン、またはキーボードショートカット一覧にあるマーカー移動ショートカットで、マーカー間を素早く移動できます。
