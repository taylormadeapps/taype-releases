# TayPE ドキュメント

TayPE ナレッジ ベースへようこそ。 TayPE は、こだわり、明確さ、そして記録の作成を中心に構築されたクラフトファーストの DAW です。

これらのドキュメントでは、知っておく必要があるインターフェイス、ワークフロー、機能について説明します。エンジニアリングの詳細な説明はなく、ただその使用方法だけを説明します。
