# コンプレッサー

レベルを制御し、パンチを加えるためのダイナミクスプロセッサー。

| Parameter | Default | Range |
|-----------|---------|-------|
| Threshold | -12 dB | -60 to 0 dB |
| Ratio | 2:1 | 1:1 to 20:1 |
| Makeup Gain | 0 dB | 0 to 24 dB |
| Attack | 30 ms | 0.1 to 100 ms |
| Release | 100 ms | 10 to 2,000 ms |
| Knee | 6 dB | 0 to 12 dB |
| Sidechain low-cut | On | fixed 80 Hz |

## レイアウト

上の行には、**しきい値**、**比率**、**メイクアップ**が表示されます。 2 行目は、**膝**、**攻撃**、**リリース**を示します。

下段のノブとゲインリダクションメーターの間には垂直ボタンスタックがあります。上のボタンは固定**80 Hz**サイドチェインローカットを有効にし、下のボタンは**LOG**リリースを可能にします。

アタックノブは**0.1ms**から始まります。ダイヤルの速い端は **0.1 ～ 1.0 ms** を 0.1 ms ステップでカバーし、次に **1 ～ 100 ms** を 1 ms ステップでカバーします。

## ゲインリダクションメーター

GR 表示は、横に目盛りが付いた垂直のトップダウン バーです。フィルなしは 0 dB GR を意味します。フルバーは 48 dB GR を意味します。メーターはライブコンプレッサーの減少値を直接追跡します。

## ログのリリース

デフォルトで有効になっています。コンプレッサーの動作が激しくなると、リリースタイムが自動的に伸びます。

これにより、より音楽的な呼吸感が得られます。コンプレッサーは、穏やかなコンプレッションではより速く回復し、強いヒットではより遅く回復するため、大きなトランジェントでのポンピングが防止されます。厳密な臨床的圧縮を行う場合はオフにします。
