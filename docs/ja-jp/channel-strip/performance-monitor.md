# パフォーマンスモニター

パフォーマンス モニターには、**プリアンプ/サミング** および **プラグイン** CPU 列が個別に表示され、トラックごとの DSP の内訳が表示されます。マスター トラックでは、プリアンプ/サミング列に NAM サミング CPU が反映されます。

## ルーティングツリー

行はマスター バスの下にルーティング ツリーとして表示されるため、バス チェーンはフラットなリストとして表示されるのではなく、視覚的にネストされます。

**Lvl** 列は、マスターからの配線の深さを示します (L0 = マスター、さらに上流のより深いレベル)。各ステージにはトラックごとの `% | ms` が表示され、表には重鎖をすばやく特定するためのトラックごとの有効なプラグイン数が含まれています。

## カラーコーディング

ステージのカラー バンドはノードごとのヒントです。

- 緑: < 12%
- 琥珀: 12～25%
- 赤: > 25%

これらはトラックごとのヒントであり、グローバルな過負荷アラームではありません。これには最上位の DSP ゲージを使用してください。

## セッションの概要

概要には次のものが含まれます。

- **クリティカル パス (est)** — 現在のブロック内の最長のアクティブな依存関係チェーン
- **スケジューラ** — レベル、最大幅、使用されるワーカー、使用率、および計算/待機/マージのタイミング
- **CPU** — すべての論理コアに対する TayPE アプリと `taype-sandbox` の合計使用量 (0 ～ 100%)。バーはアプリが緑、sandbox が青です。

トラックごとの CPU 値は読みやすくするために平滑化されています (立ち上がりが速く、立ち下がりが遅くなります)。

モニターはメイン ウィンドウの最上部に表示され、デフォルトでは 1 秒あたり 10 回更新されます。
