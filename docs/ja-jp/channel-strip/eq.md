# EQ - 3バンドパラメトリック

Neve からインスピレーションを得た 3 バンド パラメトリック EQ。各バンドには次のような特徴があります。

- **周波数** - 帯域が中心になる場所
- **ゲイン** - ブーストまたはカット、-18 dB ～ +18 dB
- **シェルフ/ベル切り替え** - シェルフカーブとベル（ピーキング）カーブを切り替えます
- **ワイド/ナロー切り替え** - 帯域幅を広くするか狭くするか

| Band | Default Frequency | Range |
|------|------------------|-------|
| Low | 220 Hz | 60 - 800 Hz |
| Mid | 1,200 Hz | 300 - 8,000 Hz |
| High | 3,200 Hz | 1,500 - 16,000 Hz |

Low と High はデフォルトでシェルフ モードになります。 Mid のデフォルトはベルです。トグルして切り替えます。
