# チャンネルストリップ

TayPE のすべてのトラックにはチャンネル ストリップが組み込まれています。信号は各ステージを次の順序で流れます。

**入力 → トリム → プリアンプ → フィルター → EQ → コンプレッサー → インサート → フェーダー → パン → 出力 **

各セクションは個別に有効化またはバイパスできます。セクションがバイパスされると、煩雑さを減らすためにその本体が非表示になります。ヘッダーは表示されたままなので、再度有効にすることができます。

![チャンネルストリップの概要](../../../assets/img/docs/timeline-with-strip.png)

## ストリップコントロール

すべてのノブは同じように機能します。垂直方向にドラッグするか、マウスホイールをホバーしてスクロールします。中立点（0 dB など）のあるノブには、通過する前に保持される戻り止めが付いています。

ゲインまたはバランスのノブをダブルクリックしてゼロにリセットします。フェーダーをダブルクリックすると、フェーダーが統一された状態に戻ります。

コンプレッサーセクションでは、マウスをノブの上に置くと、ノブのラベルがライブ値に切り替わります。

## ストリップヘッダー

色付きのタイトル バーには、トラック名が中央に丸印として表示されます。トラックの名前を変更するには、錠剤をダブルクリックします。その横にある色付きの背景をダブルクリックして、カラー ピッカーを開きます。

バス トグルはタイトル バーの左側にあり、アクティブになると緑色に塗りつぶされる白いバス グリフです。

タイトル バーの下のツール行には、**ミュート**、**ソロ**、**タグ**、**アーカイブ**、**MON**、**録音**が表示されます。入力ルーティングと出力ルーティングは、ストリップの上部の 1 行を共有します。

## ポップアップヘルプ

**ヘルプ → ポップアップ ヘルプ** を有効にすると、約 **0.7 秒**後にストリップにノブ、ルーティング セレクター、セクション ヘッダー、インサート スロット、メーター、トグル ボタンのホバー ヘルプが表示されます。
