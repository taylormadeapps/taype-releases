# プリアンプ

プリアンプは 3 つのモードのいずれかで動作します。 **MODE** ボタンを使用して、これらを順番に切り替えます。

**クリーン → クラシック → NAM → クリーン**

プリアンプ ヘッダーには、`PRE:` プレフィックスが付いた現在のモードが表示されます。 NAM モードでは、ロードされたプロファイル名も表示されます。

## クリーンゲイン (デフォルト)

プリアンプはオフです。トリム設定は色や彩度なしで通過します。新しいトラックはすべてここから始まります。

## クラシック

暖かさと彩度を加えるソフトクリッピングドライブステージ。

- **ドライブ** - 信号をクリッパーにどれだけ強く押し込むか。値が大きいほど、彩度が高くなります。
- **セーフ モード** - オーバーサンプリングを実行して、より多くの CPU を消費してより鮮明な飽和を実現します。
- **自動ゲイン (AG)** - ドライブによるラウドネスの変化を補正し、音量ではなくトーンを比較できます。

## NAM プロフィール

実際のプリアンプ (Neve 1073、API 512、SSL E、Trident など) の Neural Amp Modeler プロファイルをロードします。このプロファイルは、内蔵サチュレーターを完全に置き換えます。

**参照** ボタンをクリックしてプロファイル ブラウザを開き、TONE3000 のオンライン ライブラリを検索したり、ローカルに保存されたプロファイルから選択したりできます。

### プロファイルブラウザ

TONE3000 行には、モデルのサムネイル、タイプ、作成者、アーキテクチャ、および LSTM/AMX 互換キャプチャの AMX バッジが表示されます。サムネイルをクリックすると、tone3000.com でそのページが開きます。

**AMX 互換** フィルターは、TayPE のアクセラレーション パスに適合する LSTM キャプチャに結果を絞り込みます。ブラウザは、一致する行が見つかるまでライブラリを前方に検索します。

検索、お気に入りの更新、またはダウンロード メタデータの読み込み中にスピナーが表示されます。 TONE3000 のお気に入りの同期が一時的に利用できなくなった場合でも、スター付きプロファイルはローカルに保存されます。

### NAM コントロール

- **トリム** は常に表示され、常に NAM より前にあります。トリムを高くすると、実際のプリアンプをプッシュするように、モデルがより強く駆動されます。
- **出力ゲイン**はモデル後のレベルコントロールです。
- **自動ゲイン (AG)** は NAM レベルの前後を測定し、スムーズな補正を適用して知覚される音量を安定させます。
- **SAFE** は NAM モードでは表示されません。

### プロファイルストレージ

プロファイルは `~/Documents/TayPE/NAM/Preamps/` に保存される `.nam` ファイルです。ダウンロードしたプロファイルは、その時点からオフラインで動作します。

ダウンロードされたプロファイルはモデル タイトルのメタデータを保持するため、ストリップとブラウザにはハッシュされたファイル名の代わりにプロファイル タイトルが表示されます。サムネイルはオフラインで閲覧できるようにローカルにキャッシュされます。

プロファイルを選択する前にストリップを NAM モードに切り替えることができます。TayPE は警告を表示し、モデルがロードされるまでクリーンな状態を保ちます。

## XTALK

XTALK appears in stereo non-clean preamp modes. It blends the left and right channels into each other before the preamp colour stage, so it is different from the mixer Width control. The control uses a power-law taper: low values stay subtle, and at full value both channels receive a unity `(L + R) / 2` blend. It is hidden on mono strips.
