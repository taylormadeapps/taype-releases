# Przycięcie

Clean gain control before any processing. Use this to set your input level right before the signal hits the preamp, filters, or Korektor.

| Parameter | Range |
|-----------|-------|
| Przycięcie | -36 dB to +12 dB |

The trim knob shows a small 0 dB reference tick so you can quickly spot unity. Przycięcie is always active - it cannot be bypassed.
