# Navigation

## Défilement

- **Molette** : défiler entre les pistes
- **Balayage horizontal du trackpad** : se déplacer dans le temps
- **Clic droit + glisser gauche/droite** : panoramique temporel

Pendant la lecture, la timeline suit par pages : quand la tête atteint le bord
droit, l'affichage saute d'une page.

## Zoom

**Zoom horizontal** :
- **Cmd + molette**
- **Clic droit + glisser haut/bas**

**Zoom vertical** :
- **Option + molette**
- **Cmd+Option+= / Cmd+Option+-**
- **Cmd+Option+0**

## E-Zoom

Appuyez sur **E** pour ajuster la vue au clip sélectionné. Appuyez à nouveau
sur **E** pour revenir au zoom précédent.

## Positionnement de la tête

Cliquez n'importe où dans la timeline, hors clip, pour déplacer la tête.
**Option+clic** force toujours le déplacement, même sur un clip.

## Marqueurs

Les marqueurs appartiennent au Cut courant et restent attachés au temps absolu
de la timeline.

- Clic droit dans la règle supérieure puis **Add Marker at Playhead**
- Faites glisser un marqueur pour le déplacer
- Double-cliquez son onglet pour le nommer
- Clic droit sur l'onglet pour le supprimer ou changer sa couleur
