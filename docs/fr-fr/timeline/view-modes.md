# Modes d'affichage

Quatre filtres de vue permettent de se concentrer sur l'essentiel :

| Raccourci | Mode | Effet |
|----------|------|-------|
| F | Focus | N'afficher que les pistes avec un clip à la tête |
| A | Archive View | Basculer entre pistes actives et archivées |
| G | Spill | Afficher le bus sélectionné et les pistes qui y sont routées |
| E | E-Zoom | Zoomer pour faire tenir le clip sélectionné |

Les pistes armées et la piste sélectionnée restent toujours visibles.
