# La timeline

La timeline est l'endroit où vous voyez votre session étalée dans le temps.
Les pistes vont de haut en bas, le temps de gauche à droite, et la tête de
bande indique la position de lecture actuelle.

![Vue d'ensemble de la timeline](../../../assets/img/docs/timeline-overview.png)

## Disposition

La colonne de gauche affiche les **en-têtes de piste**. La zone principale
affiche les **clips**, c'est-à-dire des rectangles remplis de formes d'onde.

La **règle** en haut affiche le temps. Appuyez sur **T** pour basculer entre
minutes:secondes et bars|beats. Chaque Cut peut définir son propre point zéro.

La **barre de transport** se trouve en bas. Elle contient les commandes de
lecture, le BPM, la position, le sélecteur de Cut et les actions New /
Duplicate / Rename / Delete. Les boutons de vue à gauche sont **Show Mixer**,
**Focus**, **Tags**, **Spill**, **Archive**. Le bouton **?** est tout à droite.

À côté du DSP meter se trouve un petit indicateur **MCP**. Il devient rouge
quand une transaction MCP est active.

Avec **Help → Popup Help**, une aide au survol apparaît après environ
**0.7 seconde** sur les boutons, clips, fades et zones de crossfade.

### Contrôles de l'en-tête de règle

- **Channel Strip** : afficher / masquer le panneau latéral
- **+** : ajouter une piste
- **Metronome** : activer / couper le clic
- **Snap** : activer / couper l'aimantation
- **Ruler Mode** : basculer entre temps et bars|beats

Un clic droit dans la règle supérieure ouvre le menu de point zéro :

- **Set 0 at Playhead**
- **Reset 0 to Start**
