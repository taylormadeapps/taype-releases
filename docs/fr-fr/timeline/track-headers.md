# En-têtes de piste

Chaque en-tête de piste affiche les contrôles suivants.

![En-têtes de piste](../../../assets/img/docs/track-headers.png)

## Contrôles

- **Bande couleur**
- **Nom de piste**
- **Tags**
- **R**
- **MON**
- **Bus**
- **M**
- **S**
- **Tag pills**
- **Libellés I/O**
- **Mini meter**

## Nuage de tags

Cliquez sur **Tags** dans l'en-tête de piste pour ouvrir le nuage de tags.

- **Both / Global / Reel** change la portée
- Le champ de recherche filtre en direct
- Cliquez sur un tag pour l'activer ou le désactiver sur la piste
- **New Tag** permet d'en créer un nouveau en choisissant sa portée
