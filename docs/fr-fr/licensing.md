# Licence

TayPE est une application que vous payez une fois et possédez ensuite. Pas
d'abonnement, pas de frais récurrents, pas de fonctions verrouillées. Vous
l'achetez une fois, et les mises à jour prévues par votre licence sont incluses.

## Éducation

TayPE est gratuit pour les étudiants et les enseignants. Contactez-nous sur
[Instagram](https://instagram.com/ruminantaudioworks) ou
[Reddit](https://www.reddit.com/message/compose/?to=ruminantaudioworks) pour
obtenir un code.

## Accessibilité

Si vous avez des besoins d'accessibilité, TayPE est proposé avec 33 % de
réduction. Contactez-nous sur
[Instagram](https://instagram.com/ruminantaudioworks) ou
[Reddit](https://www.reddit.com/message/compose/?to=ruminantaudioworks) pour un code.

## Évaluation

TayPE inclut une période d'évaluation généreuse afin que vous puissiez le
tester sérieusement avant achat. Pas de filigrane sur l'audio, pas de
limitation artificielle, pas de barrage agressif.

## Accord

La fenêtre About contient le contrat de licence utilisateur final actuel dans
un panneau défilant, et l'installeur signé utilise exactement le même texte.
Une seule source canonique alimente les deux surfaces.
