# Documentation TayPE

Bienvenue dans la base de connaissances TayPE. TayPE est une DAW pensée
pour le craft, la décision, la clarté, et pour finir de vrais disques.

Cette documentation couvre l'interface, le flux de travail et les fonctions
à connaître. Pas de plongée dans l'ingénierie : seulement comment s'en servir.

[r/taype](https://www.reddit.com/r/taype/) ou envoyez-nous un message sur
[Instagram](https://instagram.com/ruminantaudioworks).
