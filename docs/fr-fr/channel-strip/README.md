# Tranche de console

Chaque piste de TayPE possède une tranche intégrée. Le signal suit cet ordre :

**Input → Trim → Preamp → Filters → EQ → Compressor → Inserts → Fader → Pan → Output**

Chaque section peut être activée ou bypassée séparément. Lorsqu'une section est
bypassée, son corps se masque pour réduire l'encombrement.

![Vue d'ensemble de la tranche](../../../assets/img/docs/timeline-with-strip.png)

## Contrôles

Tous les potards fonctionnent de la même manière : glisser verticalement, ou
survoler puis utiliser la molette.

Double-cliquez sur un potard de gain ou de balance pour le remettre à zéro.
Double-cliquez sur le fader pour revenir à l'unité.

## En-tête de tranche

La barre de titre colorée affiche le nom de piste dans une pilule centrée.
Double-cliquez sur la pilule pour renommer. Le bus toggle se trouve sur la
gauche de la barre.

Sous cette barre, la rangée d'outils affiche **Mute**, **Solo**, **Tag**,
**Archive**, **MON**, **Record**. Les routages d'entrée et de sortie occupent
la rangée supérieure de la tranche.

## Popup Help

Avec **Help → Popup Help**, une aide au survol apparaît après environ
**0.7 seconde** sur les potards, sélecteurs, en-têtes, slots d'insert, meters
et boutons.
