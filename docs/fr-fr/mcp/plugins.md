# Plugins

Outils pour gérer les inserts VST3.

### `list_plugins`

Retourne le catalogue des plugins VST3 scannés.

### `add_insert`

Charge un plugin dans un des 4 slots d'insert.

### `remove_insert`

Retire le plugin d'un slot.

### `bypass_insert`

Active ou désactive le bypass d'un insert.

### `get_insert_info`

Retourne l'état actuel d'un slot d'insert.

### `open_insert_editor`

Ouvre la fenêtre d'édition du plugin.

### `close_insert_editor`

Ferme la fenêtre d'édition du plugin.

### `restart_sandbox`

Redémarre le processus sandbox des plugins.
