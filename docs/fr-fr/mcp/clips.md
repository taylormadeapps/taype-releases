# Clips

Outils pour placer, déplacer et gérer les clips audio.

---

### `add_clip`

Place un fichier audio sur une piste à une position de timeline.

### `set_clip`

Déplace un clip dans la timeline ou vers une autre piste.

### `remove_clip`

Supprime un clip.

### `get_clips`

Liste les clips, éventuellement filtrés par piste.
