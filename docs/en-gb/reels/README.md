# Reels

A reel is a Taype project - your tracks, clips, mix, history, and audio,
all bundled together as a single `.taype` file in Finder.

This section covers reel-level workflows that go beyond a single
recording session.

* [Reel Upgrades](reel-upgrades.md) - what you'll see when an older reel
  needs to be upgraded for a newer version of Taype, and how to open
  reels that need a newer version than you have installed.
