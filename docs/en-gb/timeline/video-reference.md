# Video Reference

Video Reference keeps one picture file in sync with the TayPE transport for scoring work.

The video is a reference, not part of the mix. It is not edited on the timeline and it is not included in audio exports.

## Attaching Video

Drop a supported video file on the master row in the timeline or on the master channel in the mixer. TayPE accepts video formats supported by macOS, such as common `.mov`, `.mp4`, and `.m4v` files.

Dropping a video on an ordinary track is rejected. TayPE keeps one video reference per reel.

## Reference Window

The video opens in a floating reference window. Close the window when you do not need to see picture; closing the window does not remove the video from the reel.

Use **View > Show Video Reference** or `Q` to show or hide the window when a reference is attached.

## Sync and Burn-In

The reference follows the transport playhead, seek, loop, and varispeed. The burn-in follows the current ruler mode so you can work against timecode or musical position.

Use `Shift+Q` to toggle reference audio and `Option+Q` to toggle the burn-in.

## Removing or Replacing

Drop a different video on the master to replace the reference. Use the video reference controls to remove it from the reel. Removing the reference does not delete the original video file from disk.
