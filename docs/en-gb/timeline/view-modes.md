# View Modes

TayPE keeps the same reel under different working lenses.

## Timeline View

Timeline view is for recording, editing, arranging, and detailed track work.

## Mixer View

Mixer view puts strips side by side for balancing, routing, inserts, sends, and bus work.

## Tape Mode

Tape-minded layouts favour commitment and signal flow. They keep the mixer and transport close while reducing visual clutter.

## Automation View

Automation View turns the timeline lanes into an editor for the currently displayed automation parameter. Use `A` to toggle the view and `Shift+A` to cycle the displayed parameter.

See [Automation](automation.md) for capture and breakpoint editing.

## Focus, Archive, Spill, and E-Zoom

Focus narrows the working view around material at the playhead or loop. Archive View brings archived tracks back into view. Spill shows a selected bus with the tracks feeding it. E-Zoom jumps into the selected clip or working area and returns when toggled again.
