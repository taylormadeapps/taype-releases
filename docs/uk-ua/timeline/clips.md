# Фрагменти

Фрагменти - це основні елементи редагування в TayPE.

## Основні операції

- **Натисніть** - виберіть фрагмент
- **Перетягніть** - переместіть фрагмент в часі або змініть смугу
- **Cmd+Drag** - скопіюйте фрагмент
- **Перетягніть краї** - обрізайте фрагмент
- **S** - розділіти фрагмент

Редагування фрагменту неруйнівне - оригінальний аудіо ніколи не змінюється.
