# Заголовки смуг

Заголовки смуг розташовуються на лівій стороні шкали часу.

## Елементи керування

- **Назва смуги** - натисніть, щоб перейменувати
- **R** - озброєння для запису
- **S** - соло (слухайте тільки цю смугу)
- **M** - вимкнення (замовчіть цю смугу)
- **B** - перетворіть на шину
- **X** - архівуйте смугу (приховайте та вимкніть)

Колір смуги може бути змінений щодо організації та зорово.
