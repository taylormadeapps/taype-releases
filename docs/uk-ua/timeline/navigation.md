# Навігація

Посуньтеся по шкалі часу за допомогою цих команд:

- **Натисніть на лінійку** - переместіться на час
- **Перетягніть на лінійці** - скрегти через час
- **Scroll** - збільшуйте або зменшуйте масштаб
- **Tab** - перейти до наступного транзієнту
- **Option+Tab** - перейти до попереднього транзієнту
