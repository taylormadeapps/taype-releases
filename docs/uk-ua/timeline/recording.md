# Запис

## Встановлення запису

1. Виберіть смугу в заголовку
2. Встановіть вхід (наприклад, "1-2" для стереопари)
3. Натисніть **R** у заголовку смуги для озброєння
4. Натисніть **Return** для запуску запису

## Під час запису

Ви побачите червоний фрагмент-привид, що збільшується, показуючи текучий запис.

## Після запису

Натисніть **Return** для зупинення. Остаточний фрагмент з'являється з хвилепроектуванням.

Якщо записаний тейк перекриває початок або кінець наявного фрагмента, TayPE
обрізає старий фрагмент до межі нового тейка і додає лише дуже короткий
anti-click fade. Довгий автоматичний crossfade не створюється. Якщо запис
потрапляє всередину наявного фрагмента, старий фрагмент розділяється навколо
нового тейка.

Відтворення / пауза заблоковано під час активного запису; завершуйте тейк через
**Return** або **Z**.
