# Шкала часу

Вигляд шкали часу - де ви записуєте, аранжуєте та редагуєте аудіо та MIDI.

## Основні елементи

- **Заголовки смуг** (ліворуч) - керування смугами та вибір
- **Лінійка часу** (вгорі) - показує час та позицію голівки
- **Область комірок** (центр) - відображає ваші аудіо-фрагменти та MIDI-ноти
- **Голівка стрічки** (вертикальна лінія) - поточна позиція відтворення/запису

## Навігація

Натисніть будь-де на шкалі часу або лінійці, щоб переместити голівку. Перетягніть для скрегу.

## Запис

Озбройте смугу для запису, натиснувши **R**, та натисніть **Return**, щоб почати.
