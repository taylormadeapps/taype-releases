# Ліцензування

TayPE випускається як комерційне програмне забезпечення для macOS.

## Ліцензування програмної копії

Використовуйте меню **TayPE** для доступу до ліцензування:

- **TayPE > Ліцензія зараз** - коли програма не зареєстрована
- **TayPE > Ліцензія** - коли програма вже зареєстрована

Натисніть для активації ліцензії за допомогою своєї облікової запису Ruminant Audio Works.

## Залежності та відкрите джерело

TayPE включає наступні залежності:
- JUCE - фреймворк розробки аудіо-додатків
- Signalsmith Stretch - алгоритм динамічного розтягування часу
- NeuralAmpModelerCore - обробка нейронної мережі для АМ-моделювання
- libgit2 - керування історією котушок

Дивіться **TayPE > Про TayPE** для повної інформації про ліцензії.
