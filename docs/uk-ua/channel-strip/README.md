# Смуга каналу

Кожна смуга має власну смугу каналу в миксі. Вона містить всі інструменти обробки сигналу.

## Розділи

- **Передсилювач** - форматування та попередня обробка
- **EQ** - трибандний еквалайзер
- **Компресор** - динамічна обробка
- **Плагін-вставки** - розширення обробки
- **Регулятор й панорама** - гучність та позиціонування
- **Лічильник** - моніторинг рівня

## Автоматизація

Скорочення рухів регулятора та параметрів через часу за допомогою перегляду автоматизації.
