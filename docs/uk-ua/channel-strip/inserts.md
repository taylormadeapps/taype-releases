# Вставки

Вставки дозволяють вам завантажувати плагіни-розширення для обробки сигналу.

## Завантаження плагіна

Натисніть на слот вставки та виберіть плагін з браузера.

## 8 слотів

- Слоти 0-7 доступні для будь-яких плагінів
- Слот 0 - єдиний слот, який може розміщувати VSTi або MIDI Out

## Контролі

- **Вмкл/Викл** - переведіть плагін або весь рак на/вимкнено
- **Редактор** - відкрийте інтерфейс плагіна
- **Видалити** - вилучіть плагін зі слоту
