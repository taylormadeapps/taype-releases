# Монітор продуктивності

Монітор продуктивності показує поточне навантаження DSP на аудіо-потоці.

## Показання

- **% Навантаження** - відсоток доступної обробки CPU в використанні
- **RTL** - час реальної обробки

Якщо навантаження наближається до 100%, деякі плагіни можуть потребувати оптимізації або відключення.
