# Компресор

Компресор зменшує динамічний діапазон сигналу.

## Параметри

- **Поріг (THR)** - рівень, при якому починається стиск
- **Коефіцієнт (RAT)** - наскільки сильно стискається сигнал
- **Атака (ATK)** - як швидко реагує компресор
- **Відпуск (REL)** - як швидко відпускається сигнал
- **Коліно (KNE)** - м'якість переходу порога
- **Макіяж (MKUP)** - нівелювання рівня після стиску

## Режими детектора

- **FET** - швидкий, для контролю транзієнту
- **VCA** - гладкий, для компресії шини
- **OPTO** - м'який, для прозорого вирівнювання
