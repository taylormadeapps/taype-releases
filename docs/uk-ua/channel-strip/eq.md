# EQ

Еквалайзер формує частотну відповідь сигналу.

## Смуги

- **Низька (LO)** - обробка басів
- **Середня (MID)** - обробка середніх частот
- **Висока (HI)** - обробка верхніх частот

## Контролі

- **Частота (FREQ)** - яка частота редагується
- **Посилення (GAIN)** - наскільки посилити або обрізати
- **Форма (SHAPE)** - полиця або дзвіл

## Фільтри

- **Високо-пропускаючий (HP)** - обрізати низькі частоти
- **Низько-пропускаючий (LP)** - обрізати високі частоти
