# Фільтри

## Високо-пропускаючий (HP)

Обрізає частоти нижче встановленої точки. Корисно для видалення непотрібного басу та гулу.

## Низько-пропускаючий (LP)

Обрізає частоти вище встановленої точки. Корисно для придушення яскравості.

## Регулювання

Натисніть на мітку частоти, щоб змінити частоту нахилу.
