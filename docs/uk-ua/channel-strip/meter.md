# Лічильник

Лічильник показує рівень сигналу на цій смузі.

## Показання

- **Червоне** - сигнал перевищує 0 dB (відсікання)
- **Жовте** - сигнал близько до 0 dB (майже це)
- **Зелене** - нормальний рівень

## Натиснення

Натисніть на лічильник, щоб очистити утримуваний піковий та запис відсікання.
