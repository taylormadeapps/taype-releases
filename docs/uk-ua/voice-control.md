# Голосове керування

TayPE підтримує голосове керування на macOS через Siri та сумісні голосові помічники.

## Голосові команди

- "TayPE, почни запис" - почніть запис
- "TayPE, зупини запис" - зупиніть запис
- "TayPE, відтворення" - відтворення
- "TayPE, пауза" - пауза
- "TayPE, скасувати" - скасувати останню дію

## Налаштування

Налаштуйте голосові команди в параметрах TayPE на вкладці "Голос".
