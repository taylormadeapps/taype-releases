# Клавіатурні скорочення

Клавіатурні скорочення TayPE працюють через профілі. Виберіть профіль у
**Параметри > Клавіатурні скорочення**; власні профілі є файлами JSON і
відкриваються з цієї вкладки кнопкою **Редагувати JSON** у системному редакторі.

## Профілі скорочень

```
~/Documents/Taype/keybindings/
```

TayPE оновлює вбудовані профілі з пакета застосунку під час запуску:
`Default.json` (розкладка TayPE) та `Industry Standard Bruh.json`
(редакторська м'язова пам'ять у стилі Pro Tools для відповідних дій TayPE).
Вбудовані профілі доступні лише для читання й належать пакету; прямі зміни цих
файлів перезаписуються. Здублюйте профіль, щоб редагувати його;
**Перезавантажити** застосовує зміни після збереження у зовнішньому редакторі.

`Industry Standard Bruh` залишає межі лупу на `[` / `]` і призначає встановлення
лупу з виділення на `Cmd+Shift+L`, щоб звичайні стрілки лишалися навігацією
TayPE.

Старі файли `~/Documents/Taype/keybindings.json` одноразово імпортуються до
папки профілів і архівуються як `legacy-keybindings*.bak`.

## Транспорт
- **Space** - відтворення / зупинка
- **P** - відтворити / пауза (заблоковано під час запису)
- **Z** - зупинка та повернення на початок
- **Return** - запис
- **R** - озброєння смуги для запису

## Вигляди
- **M** - перемикання між шкалою часу та миксом
- **F** - перемикання режиму фокусу
- **X** - перемикання перегляду архіву
- **A** - перемикання перегляду автоматизації
- **G** - вилив (Spill) обраної шини

## Редагування
- **Cmd+Z** - скасувати
- **Cmd+Shift+Z** - повторити
- **Cmd+X** - вирізати
- **Cmd+C** - копіювати
- **Cmd+V** - вставити
- **S** - розділіти фрагмент на голівці стрічки
- **Cmd+D** - дублювати фрагмент

## Інше
- **Cmd+,** - параметри
- **?** - перемикання спливаючої довідки
- **Cmd+Shift+?** - відкрити посібник
