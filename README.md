# TayPE

**Musician-first DAW. Accessible by design. Robots welcome too.**

TayPE is a multitrack digital audio workstation for macOS built for musicians who want to finish records, not fight software. WCAG 2.2 AA accessible. AI-ready via Model Context Protocol (MCP).

## Download

Grab the latest release from the [Releases page](https://github.com/taylormadeapps/taype-releases/releases).

**Requirements:** macOS 12+ (Monterey or later). Apple Silicon native with Intel support. VST3 plugin hosting.

TayPE is fully functional demoware - download it, use it, make records. When you're ready, purchase a license.
