# TayPE

**Craft first. Accessible by design. Robots welcome too.**

TayPE is a multitrack digital audio workstation for macOS built for musicians who want to finish records, not fight software. Modelled console tone built into the engine. WCAG 2.2 AA accessible. MCP native.

## Download

Grab the latest release from the [Releases page](https://github.com/taylormadeapps/taype-releases/releases).

**Requirements:** macOS 12+ (Monterey or later). Apple Silicon native with Intel support. VST3 plugin hosting.

TayPE is fully functional trustware - download it, use it, make records. When you're ready, purchase a license.

Linux alpha ETA: Q4 2026 / Q1 2027. Windows interest list:
[taype.ruminantaudioworks.com/other-platforms/](https://taype.ruminantaudioworks.com/other-platforms/).
