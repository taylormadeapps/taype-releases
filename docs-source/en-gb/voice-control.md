# Voice Control

Voice control is an optional workflow for using TayPE through an AI assistant connected over MCP.

## Two Modes

- **Studio mode** is for spoken commands while you are working at the desk.
- **Brain mode** is for planning, notes, rough session direction, and hands-free setup.

Both modes depend on an MCP client connected to a running TayPE instance.

## What You Need

You need TayPE running, an MCP-capable AI client, and macOS permissions for any automation that types into another app or triggers shortcuts on your behalf.

## Setting Up

Use TayPE's connector installer where available, then restart the MCP client and open TayPE before starting the assistant session. The MCP page has the connector details.

## Example Commands

Try direct musical commands:

- "Add a vocal track and arm it."
- "Turn the selected track down 2 dB."
- "Open the EQ visualiser for the guitar."
- "Create a checkpoint before I try this edit."

Voice control works best when commands are specific, reversible, and tied to visible session state.

## Permissions

macOS may ask for Accessibility permissions if scripts or shortcuts need to send keystrokes. Grant only what you understand, and keep the workflow local to your machine.
