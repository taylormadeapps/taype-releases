# Stem Splitter

Stem Splitter separates a source into musical stems when the required model support is available on your Mac.

## What It Does

Choose a clip or source, run Stem Splitter, and TayPE renders separate stem tracks such as vocals, drums, bass, and other material depending on the model package. The original remains available so you can compare, mute, archive, or rebuild the arrangement.

## Model Setup

Stem Splitter uses bundled model support where available. If the model package is missing or unsupported on the current machine, TayPE explains what is unavailable instead of pretending the render can run.

## Rendering

Stem splitting is an offline render. TayPE shows progress, creates new tracks for the result, and keeps the operation undoable where the surrounding reel state allows it.

## Practical Use

Use stems for arrangement decisions, restoration, rough remixing, and isolating parts for creative processing. Treat the result as a musical tool, not a guarantee of perfect source separation.
