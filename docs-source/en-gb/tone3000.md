# TONE3000 and NAM Profiles

TayPE's NAM profile browser can load local amp profiles and work with TONE3000 packages where online search and download are available.

## Local Profiles

Local profiles live in TayPE's profile library. The browser groups profiles by package and model so you can find the right amp or pedal without digging through file names.

## TONE3000 Search

The TONE3000 tab lets you search online packages, inspect metadata, and download the full package into the local library. Once downloaded, the model appears beside your local profiles and can be loaded into the preamp.

## Loading A Profile

Open the preamp profile browser, choose a profile, and load it onto the selected track. TayPE keeps the profile assignment with the reel so the tone comes back when the session reopens.

## Sign-In Status

Where TONE3000 needs authentication, TayPE shows sign-in status in the browser and welcome surfaces. If authentication expires, sign in again before searching or downloading.

## Stock Plugins

TayPE Drive can use the same profile library outside the main app when hosted as a TayPE stock insert. The bundled stock plugins are designed for TayPE's own environment and stay safe if opened elsewhere.
