Cookie Policy

Last updated: 23 July 2026

This website does not use analytics cookies, advertising cookies, tracking pixels, or social widgets.

There is one narrow exception: if you arrive through an affiliate link, we offer you a choice about referral tracking. Lemon Squeezy's affiliate script is not loaded unless you choose Allow referral tracking or this browser already has the affiliate cookie from an earlier choice.

Affiliate tracking

Affiliate links contain a short referral code. If you allow tracking, the page loads Lemon Squeezy's affiliate script. The script sends Lemon Squeezy the referral code, the page URL, the referring page, and a device-derived browser identifier. Lemon Squeezy returns a click identifier and stores it in a cookie named ls_aff_ref.

The cookie lasts for 30 days. Its only purpose on this site is to connect a later TayPE purchase with the person who referred you. That person receives 20% commission; your price does not change.

If you choose Continue without tracking, the referral code is removed from the address, the Lemon Squeezy script is not loaded, and no affiliate cookie is created.

Local browser storage

The site may store your language preference in your browser using local storage. That is not a cookie, and it is not sent to us. It only helps the site remember which language you picked.

You can clear it at any time from your browser's site data settings.

Change your affiliate choice

You can remove the affiliate cookie from this browser here. This prevents this site from using the existing click identifier on future visits. To request erasure of a referral record already held by Lemon Squeezy on our behalf, email us at the address below.

If this changes

If we add any other cookies or similar tracking technology, we will update this page first and ask properly where consent is required.
